Do not copy a contributor’s FSL patch into proprietary Apito Cloud code unless the contribution terms expressly permit that copy. Counsel decides whether a narrow agreement is required before that happens. Preserve attribution and contributor credit either way.

## Do not call this open source

A current FSL version is Fair Source. It becomes Apache 2.0 on the change date published with that release. Tags that already shipped as Apache 2.0 remain Apache 2.0.

## Tests

Ship tests with the change. Self-hosted behavior (models, content, tenants, schema draft and publish, project database explorer) must keep working without a license key and without calling Apito Cloud.
